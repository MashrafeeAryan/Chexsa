# FridayV2

FridayV2 is a general-purpose computer agent designed to complete end-to-end tasks directly on your computer.

* Understand natural-language requests and plan multi-step tasks.
* Control Chrome and interact with websites such as Handshake and Canvas.
* Work across desktop applications such as Microsoft Word.
* Observe and verify its actions instead of blindly executing commands.

## Goal

Build a local computer-use agent with capabilities similar to ChatGPT Work.
